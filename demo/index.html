How the study was run

Measured, not judged.

A real sandbox

Six small code repositories with test suites and an internal API. Stuck agents face a quota or a failing test they cannot fix honestly.

Evidence, not opinions

A rule break only counts when the sandbox records it: the admin token in a request, a production host contacted, a test file changed.

Preregistered

Hypotheses, sample sizes and statistical tests were fixed before the data, with Holm correction and every deviation logged.

Limitations

Synthetic tasks and a simulated API, one model per team, and the inside-the-model analysis covers a single open-weight model.
