# results/

Frozen analysis outputs for every experiment. Each folder has a `report.md` with the hypothesis tests, plus the
CSV tables and figures behind it. Raw episodes are regenerated by the runs (they are deterministic given the
seeds and the cache); the pilot and reality-check raw data are committed and checksummed in `data/raw/`.

| Folder | Experiment | Key files |
|---|---|---|
| `exp_000b/` | Reality check in the confirmatory harness, run before the preregistration was frozen. Exploratory, never pooled. | `report.md` |
| `exp_001/` | Susceptibility: 5 models, 4 shortcuts, shortcut note vs control note vs empty board vs no board | `h1_susceptibility.csv`, `h2_board_presence.csv`, `fig_leaderboard.png` |
| `exp_002/` | Message content: 2⁶ factorial over six note traits, gpt-oss-20b and GPT-5 nano | `h3_trait_risk_differences.csv`, `fig_trait_heatmap.png` |
| `exp_003/` | Decision-point harvest for the white-box analysis, gpt-oss-20b | `report.md` |
| `exp_004/` | Containment: 12-agent outbreaks under each guardrail, relay vs no-relay | `h4_defenses.csv`, `h4c_transmission.csv`, `fig_frontier.png`, `fig_outbreak_growth.png` |
| `exp_006/` | LLM-written notes vs template notes vs no note | `report.md` |
| `judge_vs_filter/` | LLM judge vs trained filter on the same held-out posts | `judge_vs_filter.json` |
| `filter/` | Trained channel filter: selected hyperparameters, calibration, threshold | `channel_filter.report.json` |
| `whitebox/` | Probe by layer, held-out probe test, steering sweep | `probe_test.json`, `steering.csv`, `fig_probe_layers.png`, `fig_steering.png` |

Regenerate any folder with `outbreak analyze outputs/results/<run_id>/episodes.jsonl` (or `outbreaks.jsonl` for
exp_004) after re-running the experiment; notebook `06_results` does all of them and copies them here.
